# 🎯 RACI Quest

Командная игра для брейнсторминга RACI-матрицы в реальном времени.  
Все участники видят одно и то же состояние — голоса, новые роли и задачи мгновенно синхронизируются.

---

## 🚀 Деплой за 10 минут

### Шаг 1 — Получи Liveblocks Public Key (бесплатно, 2 мин)

1. Зайди на [liveblocks.io](https://liveblocks.io) → Sign Up (GitHub логин)
2. Создай новый проект: Dashboard → **New project** → любое название, например `raci-quest`
3. Перейди в проект → **API Keys** → скопируй **Public Key** (начинается с `pk_prod_...`)

---

### Шаг 2 — Задеплой на Vercel (3 мин)

**Вариант А: через GitHub (рекомендую)**

1. Создай новый репозиторий на GitHub (можно приватный)
2. Загрузи все файлы этой папки в репо
3. Зайди на [vercel.com](https://vercel.com) → **New Project** → импортируй репо
4. В разделе **Environment Variables** добавь:
   - Key: `VITE_LIVEBLOCKS_PUBLIC_KEY`
   - Value: твой ключ `pk_prod_...`
5. Нажми **Deploy** → через минуту получишь URL типа `raci-quest.vercel.app`

**Вариант Б: через Vercel CLI**

```bash
npm i -g vercel
cd raci-quest
cp .env.example .env.local
# Открой .env.local и вставь свой ключ
vercel --prod
# При деплое Vercel спросит про env vars — введи VITE_LIVEBLOCKS_PUBLIC_KEY
```

---

### Шаг 3 — Играть!

1. Открой URL → нажми **"Создать новую игру"**
2. Скопируй ссылку (или код комнаты) → кинь в Slack/Telegram команде
3. Все открывают ссылку → видят тот же экран настройки в реальном времени
4. Ведущий нажимает **"Начать игру"** → погнали!

---

## 🎮 Как работает игра

**Ведущий** может:
- Добавлять/удалять роли и задачи **прямо во время игры** (кнопки `+ роль`, `+ задача` в хедере)
- Переключать раунды, открывать результаты
- Перейти к любой задаче через "все задачи"
- Начать заново

**Участники** могут:
- Голосовать R / A / C / I для каждой роли в текущей задаче
- Видеть счёт команды в реальном времени

**Синхронизируется у всех:**
- Голоса (сразу как кто-то нажал)
- Новые роли и задачи
- Переключение раундов
- Результаты
